Task 11.11.2026 / Project proposal

Runbook Navigator

An incident assistant that shows the instructions behind its answer.

I propose a web application for investigating fictional technical incidents with approved runbooks. It will retrieve relevant passages, draft a structured response and show the source and document version for each recommendation. A human reviews the result before export.

Read the project proposal PDFExisting RAG coursework

Planned first version

Incident input, keyword and vector retrieval, structured answers, citation validation and a review screen. The application will report insufficient evidence when the documents do not support an answer. It will use fictional classroom data and will not execute production actions.

Status: proposed application. The proposal describes a planned implementation and acceptance targets.

Repository review

RepositoryWhat it containsHow it informs my idea
